# Security and bug reporting

## Ordinary bugs

For a problem without a security impact, open an
[issue](https://github.com/Eneru/soulkiller/issues) using the bug template.
Write the report in English and include reproduction steps, expected and actual
results, the version or commit, and logs with secrets and personal data removed.

## Suspected vulnerabilities

Do not publish keys, personal data, sensitive exploit demonstrations or details
that enable exploitation in a public issue.

If GitHub displays **Report a vulnerability** in the
[Security tab](https://github.com/Eneru/soulkiller/security), use that private
channel. Availability depends on repository settings; this initial setup does
not change them.

Otherwise, ask the maintainer [Eneru](https://github.com/Eneru) for a private channel.
If no private contact is listed on the profile, an issue may only request that
channel, without describing the vulnerability.

Once a private channel is established, provide:

- The affected commit or version and relevant context.
- The potential impact and a minimal reproduction using synthetic data.
- Any known mitigations.

## Support

The project is being initialized and has no released version with a support
commitment. The maintainer will review reports without a guaranteed response or
fix deadline. Coordinate disclosure and any fix publication with the maintainer.
