# Invented manual example

Five explicit manifest entries: two UTF-8 TXT documents, one deliberately invalid
UTF-8 TXT and two native text PDFs (French: two pages; English: one page).
All identities and statements are invented. No source came from personal data.

PDF bytes were generated with the maintained synthetic_pdf.build_text_pdf helper.
The independently declared facts are Inez's blue lamp on French page 1 and
Corin's paper stars on English page 1. They were not derived from parser output.
Manifest SHA-256 values freeze these bytes. Changing a source requires explicitly
updating its reference metadata/hash. Follow the repository's try-extraction guide.
