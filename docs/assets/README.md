# GitHub App avatar

The avatar is an original AI-generated portrait for `eneru-soulkiller-agent`,
inspired by a fictional cyberpunk netrunner archetype. It uses no supplied
screenshot, official artwork or logo. This describes its creation, not a legal
guarantee of copyright clearance.

Use the square [upload PNG](eneru-soulkiller-agent.png) (200 × 200 pixels,
76,377 bytes). The [circular preview](eneru-soulkiller-agent-circle.svg) displays
GitHub-style masking without changing the upload file. Its face, eyes and chin
remain inside the central circular area; keep the entire square when GitHub
offers a crop. The dark navy background fits the App badge.

GitHub accepts PNG/JPG/GIF logos below 1 MB and recommends 200 × 200 pixels.
See [GitHub App badges](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/creating-a-custom-badge-for-your-github-app).
The maintainer uploads it under **Developer settings → GitHub Apps →
eneru-soulkiller-agent → Display information → Upload a logo → Set new avatar**.
No App settings are changed by the publication tool.
