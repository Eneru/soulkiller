# GitHub App avatar

The avatar is AI-generated artwork of Alt Cunningham from Cyberpunk 2077,
created from the previous generated portrait and the maintainer's requested
character details. It uses a detailed 1990s manga style: weathered blonde hair,
a swept-back central fringe, freckles, a broader nose, pink lips and pastel
shading. No official screenshot or logo was supplied as a reference.

Use the square [upload PNG](eneru-soulkiller-agent.png) (512 × 512 pixels,
656,665 bytes). The [circular preview](eneru-soulkiller-agent-circle.svg) displays
GitHub-style masking without changing the upload file. Keep the full square
when GitHub offers a crop; the face, eyes and chin remain within the circle.

GitHub accepts PNG/JPG/GIF logos below 1 MB and recommends 200 × 200 pixels;
this larger upload preserves the artwork's drawn detail while meeting the size
limit. See [GitHub App badges](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/creating-a-custom-badge-for-your-github-app).
The maintainer uploads it under **Developer settings → GitHub Apps →
eneru-soulkiller-agent → Display information → Upload a logo → Set new avatar**.
No App settings are changed by the publication tool.
